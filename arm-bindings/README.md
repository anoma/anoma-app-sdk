# @anomaorg/arm-bindings

WebAssembly bindings for [`anoma-rm-risc0`](https://github.com/anoma), the Anoma
resource machine. Provides resources, digests, nullifier keys, authorization
signatures, Merkle trees and encryption primitives to TypeScript.

> **Web only.** This release ships the wasm target. React Native (iOS/Android)
> bindings are generated by the same Rust crate but are not published yet.

## Install

```bash
pnpm add @anomaorg/arm-bindings
```

## Usage

The wasm module must be initialised once before any binding is used.

```ts
import { initSdk, Digest, randomBytes } from "@anomaorg/arm-bindings";

await initSdk();

const nonce = Digest.fromBytes(randomBytes());
console.log(nonce.toHex());
```

`initSdk()` locates the wasm binary relative to the module's own URL, so
bundlers that understand `new URL(..., import.meta.url)` (Vite, webpack 5,
Rollup, Metro) resolve it without extra configuration.

## Building from source

Requires a Rust toolchain, the `wasm-bindgen` CLI, and `wasm-opt` (binaryen).

```bash
pnpm build          # release wasm + optimise + bundle
pnpm build:dev      # debug wasm, no optimise
pnpm smoke          # load the built bundle and round-trip a digest
```

[`scripts/smoke.mjs`](./scripts/smoke.mjs) imports `dist/` exactly as a consumer
would, so it fails if the wasm lookup or the published `files` list breaks.

`ubrn build web` compiles the crate in [`rust/`](./rust) and generates the
TypeScript bindings into `generated/`, which is not committed. `wasm-opt -Oz`
then cuts the binary by roughly a third, and `tsdown` bundles
[`src/index.ts`](./src/index.ts) into `dist/`.

The wasm-bindgen crate version is pinned in
[`wasm-cargo-patch.toml`](./wasm-cargo-patch.toml) and must be bumped together
with the CLI version installed in
[`.github/workflows/arm-bindings.yml`](../.github/workflows/arm-bindings.yml).
